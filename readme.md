# TeamFinder

Django-проект для поиска команды в pet-проекты. Реализован вариант `#1`: избранное, участие в проектах, фильтрация пользователей, публичные профили, регистрация и аутентификация.

## Что реализовано

- кастомная модель пользователя с авторизацией по `email`
- список проектов и список пользователей с пагинацией
- регистрация, вход, выход, редактирование профиля, смена пароля
- создание, редактирование и завершение проектов
- добавление проектов в избранное
- вступление в чужие проекты
- фильтрация пользователей по критериям варианта 1
- тестовые данные для ручной проверки
- Dockerfile и `docker-compose.yml` для запуска проекта с PostgreSQL
- автоматические тесты

## Локальный запуск через venv

1. Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте `.env`:

```bash
cp .env_example .env
```

Значения из примера подходят для локального запуска. В Docker Compose
`POSTGRES_HOST` для контейнера `web` переопределяется автоматически.

4. Поднимите PostgreSQL:

```bash
docker compose up -d db
```

5. Примените миграции:

```bash
python manage.py migrate
```

6. Создайте суперпользователя:

```bash
python manage.py createsuperuser
```

7. Загрузите тестовые данные:

```bash
python manage.py seed_demo_data
```

8. Запустите сервер:

```bash
python manage.py runserver
```

Проект будет доступен по адресу `http://127.0.0.1:8000`.

## Запуск через Docker Compose

1. Создайте `.env`:

```bash
cp .env_example .env
```

2. Поднимите проект:

```bash
docker compose up --build
```

Приложение будет доступно по адресу `http://127.0.0.1:8000`, PostgreSQL по адресу `127.0.0.1:5432`.

Контейнер `web` при запуске выполняет:

- `python manage.py migrate`
- `python manage.py collectstatic --noinput`
- `python manage.py runserver 0.0.0.0:8000`

Данные PostgreSQL сохраняются в named volume `postgres_data`.

## Полезные команды

```bash
python manage.py test
```


## Тестовые аккаунты

Команда `python manage.py seed_demo_data` создаёт пользователей:

- `anna@example.com`
- `boris@example.com`
- `maria@example.com`

Пароль у всех одинаковый: `TeamFinder123`

У каждого пользователя создаётся минимум один проект, а также связи избранного и участников для проверки функциональности.

- создание, редактирование и завершение проекта

- добавление в избранное с главной и со страницы проекта
- страница избранного
- фильтры на странице пользователей
- смена пароля
